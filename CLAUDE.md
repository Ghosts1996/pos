## 6. Открытые вопросы и известные ограничения

- **НПД:** лимит 2,4 млн ₽/год; бухгалтеру уточнить, подходит ли формулировка оферты «право использования программы» для НПД.
- **Пакет Android** оставлен `com.hookahpossaas` (менять только перед публикацией в сторах, по безопасному плану).
- **Защита — что учесть:** сам владелец, 5 раз ошибившись при входе по SSH, закроет свой адрес на час (вход через консоль хостинга работает). Пороги щита рассчитаны на CGNAT мобильных операторов — не снижать без причины. Касса (Flutter) на замок почты показывает общее «слишком много попыток» (код 429), текст сервера — только в кабинете. От большой DDoS-атаки один VPS не спасёт — нужна российская служба защиты от DDoS перед сервером (решение и оплата — за владельцем). nginx-лимиты (`limit_req`) не ставили: правило «update-server.sh не трогает nginx».
- **Карта — память сборки дорог (13.11.2026):** osmium extract/tags-filter всегда берут ~2 ГБ (наборы номеров узлов по всей России), а сборке разрешено 900 МБ — дороги не собирались, маршрут не строился. Теперь `map-build.js` режет район и дороги через osmconvert/osmfilter (`--hash-memory=200`, пакет osmctools ставится сам, ~0,5 ГБ), затем `osmium add-locations-to-ways -i sparse_mem_array --ignore-missing-nodes`. Проверено на Северо-Западе: граф Петербурга 29 МБ, маршрут Невский 28 → Университетская наб. 3 — авто 3 км/8 мин, 20 мс. Не запускать `node map-build.js` в песочнице «для справки» — он сразу начинает сборку.
- **Районы города:** первая сборка с районами на сервере пойдёт после деплоя 14.11.2026 (по всем ~85 городам — отдельный проход, часы); пока файла `districts-<район>.json` нет, кабинет пишет «карта соберётся в течение суток». Проверено на выгрузках OSM в песочнице, на сервере — посмотреть `/var/log/zalpos-map.log` («районы: … готовы»).
- **Карта:** своя карта и маршруты курьера работают с нашего сервера (`docs/delivery.md`, раздел 17). С 13.11.2026 своя карта и в кабинете («Доставка → Сейчас»), на странице заказа гостя и на странице «Адрес и карта» из бота (`map/zal-embed.js`). Первая сборка карты на сервере проверена только по частям (pmtiles, osmium, граф) — после первого запуска посмотреть `/var/log/zalpos-map.log`. Курьер службы доставки проверен только на подменённых ответах — первый реальный вызов делать тестовым.
- **Доставка, шаг 2** (см. `docs/delivery.md`, раздел 12): курьер в карточке кассы, цена доставки и районы в APK гостя (старые версии: базовая цена, «назовите при звонке»), геокодер для цены по расстоянию; строка о геолокации курьеров в политике ПД.
- **Не сделано из пожеланий:** запрет продажи в минус; SMS-канал для «Вернуть гостя» (нужен российский SMS-провайдер). Открытый API (только чтение) и «Вернуть гостя» — сделаны; промокоды и сертификаты уже были.
- **Flutter на GitHub — всегда последний stable** (`subosito/flutter-action`, `channel: stable`, без версии) и `flutter pub get --enforce-lockfile`: с выходом новой версии Flutter сборки падают на «Unable to satisfy pubspec.yaml using pubspec.lock» (так было 12.11.2026 с Flutter 3.50 — test_api, vector_math, listen). Лечение — `flutter pub get` той же версией и коммит `pubspec.lock`. Flutter 3.50 требует Java 21 (иначе Android lint падает на `List.removeLast`): с разрешения владельца 12.11.2026 в `build-apk.yml`, `public-apk-release.yml`, `saas-on-demand-build.yml` стоит `java-version: 21` (`courier-apk.yml` — без Flutter, Java 17). Flutter можно поставить в песочницу (`storage.googleapis.com/flutter_infra_release/releases/stable/linux/…tar.xz`, ~1 ГБ, распаковать в scratchpad) — тогда работают `flutter test` (611 тестов, ~30 с) и `flutter analyze`.
- **Проверка CI без gh-токена:** репозиторий публичный — `gh run list -R ghosts1996/pos`, `gh run view <id> -R ghosts1996/pos --log` работают и без входа; так проверять «Обновление сервера» и сборку кассы (`public-apk-release.yml` гоняет `flutter test` и сборку на каждый push в `lib/**`).
- **Локальный стенд в песочнице:** `TELEGRAM_SECRET_KEY` подписывает и входы — держите его постоянным между перезапусками, иначе сохранённые сессии гостя получат 401.
- **Песочница без npm:** тесты сервера можно гонять с заглушкой firebase-admin (только Timestamp/FieldValue/FieldPath) через `NODE_PATH`; `test.rules-local.js` (mocha) и тесты `pii-gateway` (pg) без пакетов не запускаются.
- **Курьеры — что сверить:** условия для курьеров (`rules.html`), оферту п. 7.9 и политику ред. № 7 показать юристу; в уведомлении РКН категория «курьеры заведений» (по поручению заведений). Письма с кодом зависят от почты сервера (SMTP в `/etc/saas-gateway.env`) — без неё вход курьеров невозможен (кабинет покажет «Почта сервера не настроена»). Нет уведомления курьеру о назначенном заказе, кроме звука в открытом приложении/службы APK.

## 7. Как работать с владельцем

Он присылает скриншоты и видео с телефона (видео можно разбирать ffmpeg покадрово). Пишет коротко и эмоционально — пойми суть, найди настоящую причину, исправь, проверь, закоммить в `production`, дождись деплоя и коротко отчитайся по-русски: что было, что исправил, что проверено, что сделать ему самому.
