## 2. Что такое ZalPOS

SaaS-касса и система управления для общепита (кальянные, кафе, бары, рестораны, сети). Владелец платформы — **ИП Бикоев Константин Николаевич** (НПД/самозанятый, ИНН 151211052290, ОГРНИП 326150000028364, email zalpos@mail.ru). Цель — продукт лучше конкурентов (iiko, r_keeper, Poster, Quick Resto и др.), законный по 152-ФЗ, без лагов, всё данные в РФ.

Части:
- **Касса** — Flutter (`lib/`), Android и Windows. Пакет Android `com.hookahpossaas` (решили НЕ менять).
- **Приложение гостя** — Flutter APK под брендом заведения (`lib/client/…`) и веб-версия `saas/guest-web/app/` (для iPhone, по QR стола), страница стола `saas/guest-web/table.html`.
- **Кабинет и лендинг zalpos.ru** — `saas/console/` (один большой `console.js`, без сборщика; `index.html` с пререндером лендинга; `guide.js` — инструкция; `heal.js` — самолечение).
- **Блог** — `saas/blog/posts/*.md`, публикуется таймером по датам (`saas/scripts/build-blog.mjs`, `blog-publish.sh`), правила в `saas/scripts/test-blog.mjs`.
- **Сервер `saas-gateway/`** (Node.js, `server.js` ~9 тыс. строк): API, свой вход (`own-auth.js`), свой сервер данных SQLite + правила firestore.rules (`data-server.js`, `rules-engine.js`, клиенты `saas/console/zal-db.js` = копия в `saas/guest-web/app/zal-db.js`, должны совпадать), бот поддержки (`support-bot.js`, база знаний `support-kb.js`, шаблоны `support-templates*.js`), партнёрская программа (`partners.js`, договор `partner-contract.js`), Telegram-боты заведений (`telegram.js`), оплаты (`guest-pay.js`, Робокасса), ИИ-ключи (`ai-keys.js`), бумаги владельцу (`legal-papers.js`), склад/УПД (`saas/console/upd-import.js`).
- **`pii-gateway/`** — справочник персональных данных в РФ (PostgreSQL).

## 6. Открытые вопросы и известные ограничения

- **VPN:** с зарубежными серверами многих VPN сайт не открывается (VPN не пускают на российские сайты; с российским сервером VPN работает). Решение — исключение zalpos.ru в VPN; зарубежный посредник нельзя (152-ФЗ). Подсказка уже в боте менеджеров и в плашке `heal.js`.
- **8 умеренных уязвимостей** внутри firebase-admin — нужна мажорная версия, не трогали.
- **НПД:** лимит 2,4 млн ₽/год; бухгалтеру уточнить, подходит ли формулировка оферты «право использования программы» для НПД.
- **Пакет Android** оставлен `com.hookahpossaas` (менять только перед публикацией в сторах, по безопасному плану).
- **Не сделано из пожеланий:** запрет продажи в минус, авто-рассылки «вернуть гостя» (сегменты «давно не был» по `lastVisitAt` гостя). Открытый API — сделан (только чтение; запись заказов через API — следующий шаг).
- **Песочница без npm:** тесты сервера можно гонять с заглушкой firebase-admin (только Timestamp/FieldValue/FieldPath) через `NODE_PATH`; `test.rules-local.js` (mocha) и тесты `pii-gateway` (pg) без пакетов не запускаются.
- У владельца на бумаге: подписать приказ № 1-ПД, порядок уничтожения, вести журнал обращений; дождаться номера РКН.
