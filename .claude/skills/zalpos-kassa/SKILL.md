# Касса и приложение гостя (Flutter)

- Код `lib/` общий с проектом hookah-pos (Colibri Lounge). Любое изменение поведения — только под
  `kSaasMode` (из `lib/build_info.dart`) или `AppScope.isSaasMode`. Однозаведенческая сборка должна
  работать как раньше.
- Данные: в SaaS касса работает со своим сервером через `lib/data/local_engine.dart` и
  `local_firestore.dart` (совместимы с cloud_firestore). `AppDb.isLocal` — данные на своём сервере.
- Без интернета: записи копятся в очереди и уходят после связи; транзакции офлайн идут по локальной копии.
  Новый код должен работать офлайн: не ждать ответа сервера там, где кассир стоит у кассы,
  использовать `Source.cache` при `NetStatus.online.value == false`.
- Вход в SaaS — свой (`lib/services/app_auth.dart`), не Firebase Auth напрямую.
- Деньги считать без потерь округления; смена: X-отчёт промежуточный, Z-отчёт закрывает смену,
  номера Z сквозные, выручка = продажи − возвраты.
- Тексты в интерфейсе — грамотный русский без кавычек и «ИИ-вставок», слова не вылезают из кнопок.
- Тесты кладутся в `test/`. Flutter в песочнице обычно нет: проверка — сборкой на GitHub после push
  (смотри результат workflow публичной сборки). Если сборка упала — чинить сразу.
- Пакет Android `com.hookahpossaas` не менять. Workflows не трогать.
