# Блог ZalPOS

- Посты — `saas/blog/posts/*.md`, публикует таймер по датам (`saas/scripts/build-blog.mjs`, `blog-publish.sh`).
  Карта сайта и уведомление поисковиков (IndexNow) обновляются сами.
- Шапка поста:
  ```
  ---
  date: 2027-04-14
  slug: latinica-cherez-defis
  title: 15–120 символов
  description: 70–200 символов, с главным поисковым запросом
  tags: Работа в ZalPOS, Персонал
  ---
  ```
- Темы только из списка: Выбор системы, Сравнения, Законы и кассы, Финансы, Склад и меню, Персонал,
  Гости и маркетинг, Открытие заведения, Работа в ZalPOS, Кальянные, Сезон и праздники.
- График: по 2 поста на дату, даты через день. Новые посты — в конец очереди (смотри последнюю дату
  в самом позднем файле). Сезонные (Новый год, Чёрная пятница) — на свои даты.
- В каждом посте минимум 2 раздела `##` и минимум 1 ссылка на другой пост `/blog/<slug>/`.
- Проверка: `node saas/scripts/test-blog.mjs` — должна пройти.

## Стиль
Пишет владелец заведения/практик, а не нейросеть: короткие абзацы, конкретные цифры и ситуации из зала,
без «в современном мире», «давайте разберёмся», цепочек тире, восклицаний и списков ради списков.
Правильные переносы строк, без лишних кавычек.

## Закон
- Сравнения с конкурентами — только проверяемые факты со ссылкой на открытый источник
  (сайт конкурента, его справка, тарифы). Не выдумывать, без «лучший», «№1».
  Нет источника — не писать о системе (так решили про YUMA, Restocrm, Restik).
- Названия конкурентов можно использовать для статей о переходе («как перенести данные из …»).
