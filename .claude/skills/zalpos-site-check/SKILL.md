# Проверка сайта и сервера снаружи

Из песочницы zalpos.ru и pii.zalpos.ru напрямую недоступны. Блокировку прокси не обходить.

1. Запусти проверку с узлов в России и других странах:
   `https://check-host.net/check-http?host=https://zalpos.ru&max_nodes=20`
   (заголовок `Accept: application/json`), через пару секунд — результат по
   `https://check-host.net/check-result/<request_id>`.
   То же для `https://pii.zalpos.ru/saas/health` — ответ должен содержать `"version"` с началом
   последнего коммита в production.
2. Россия открывает, заграница нет — это ожидаемо (VPN с зарубежным сервером). Решение для людей —
   исключение zalpos.ru в VPN; зарубежный посредник нельзя по 152-ФЗ.
3. Не открывается нигде — смотри последний запуск «Обновление сервера» (GitHub MCP `actions_list`,
   `get_job_logs`). Сторож `self-heal.sh` сам перезапускает службы каждые 2 минуты.
4. Медленно, но открывается — проверь вес и сжатие файлов, пререндер лендинга
   (`saas/scripts/prerender-landing.mjs`), кэш статуса в `console.js`.
5. Веб-часть локально: стенд `saas-gateway/test-data-harness.js` + статический сервер копии
   `saas/console`, Playwright. Синтаксис всех веб-скриптов проверяет `test.web-syntax.js`.

Команды на самом сервере выполняет владелец; пиши их готовыми к копированию и объясняй простыми словами.
