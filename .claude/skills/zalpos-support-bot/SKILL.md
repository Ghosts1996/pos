# Бот поддержки ZalPOS

Файлы (все в `saas-gateway/`):
- `support-bot.js` — логика: SYSTEM_CORE + условные части промпта (PROMPT_PARTS), шаблоны, эскалация, темы в группе.
- `support-kb.js` — база знаний: статьи `A(id, title, text, kw)` и `CORE_FACTS` (проверенный список возможностей).
- `support-templates.js`, `support-templates-more.js` — готовые ответы `T(id, [вопросы], ответ, {audience, direct})`;
  отвечаются без ИИ, токены не тратятся.
- Инструкция `saas/console/guide.js` тоже идёт в поиск бота и в шаблоны.
- `test.support.js` — тесты бота.

## Порядок работы
1. По скриншоту найди настоящую причину: не нашлась статья, шаблон перехватил чужой вопрос,
   бот рано позвал человека, неверный факт.
2. Новая функция продукта → строка в `CORE_FACTS` + статья в `support-kb.js` + при частом вопросе шаблон.
   Факты бери из кода, а не из памяти.
3. Частый простой вопрос → шаблон. Если ответ зависит от ситуации — `direct: false` (только подсказка ИИ).
   Проверь, что новый шаблон не перехватывает существующие тесты.
4. Добавь тест в `test.support.js` на конкретный вопрос владельца.
5. Дальше — навык `zalpos-ship`.

## Закон и правила
- Не называть и не сравнивать конкурентов, без «лучший», «№1» (38-ФЗ, 135-ФЗ).
  Исключение — как выгрузить данные из старой программы клиента.
- Не раскрывать ключи, пути на сервере, внутренние адреса.
- На сайте бот приоритетнее человека: сначала отвечает сам, человека зовёт только после подтверждения.
  Специалист отвечает до 24 часов.
- В текстах для клиентов про Telegram в юридическом смысле — «мессенджер».
